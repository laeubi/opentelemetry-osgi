# OpenTelemetry OSGi Incubator

This folder contains experimental and in-development modules that are not yet ready for production use.

## Modules

| Module | Description | Details |
|---|---|---|
| [opentelemetry-osgi-agent](opentelemetry-osgi-agent/README.md) | OpenTelemetry Java Agent extension for OSGi framework instrumentation via ByteBuddy | [Read more →](opentelemetry-osgi-agent/README.md) |

> **Note:** The agent approach is complementary to the DS-based [integrations](../integrations/README.md) and OSGi-native [weaving](../weaving/README.md) modules.
> Consider using the weaving modules for production deployments.
